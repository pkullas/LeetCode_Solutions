# Problem: Contains Duplicate (Easy)

Link: https://leetcode.com/problems/contains-duplicate/

## Approach

I used nested loops to compare every pair of elements in the array. If two elements are equal, the array contains a duplicate.

## Complexity

Time: O(n²)
Space: O(1)

## Notes

Tested the program with two test cases. The first contains a duplicate value, and the second contains only unique values.
