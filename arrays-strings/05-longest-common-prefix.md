# Problem: Longest Common Prefix (Easy)

Link: https://leetcode.com/problems/longest-common-prefix/

## Approach

I compared the characters of the first string with the corresponding characters of the other strings. I continued until a character was different or one of the strings ended.

## Complexity

Time: O(n × m)
Space: O(m)

## Notes

Tested the program with two test cases. The first has a common prefix of "fl", and the second has no common prefix.
